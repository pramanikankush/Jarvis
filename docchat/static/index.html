          Settings
          Groq daily token usage

          Your keys are stored only on this machine (data/config.json) and sent only to api.groq.com / api.tavily.com. You can also set the GROQ_API_KEY and TAVILY_API_KEY environment variables (those win over the UI). The optional Tavily key enables web search; without it, search falls back to the built-in keyless DuckDuckGo. Speech-to-text and text-to-speech also use Groq (Whisper + Orpheus). Embeddings and storage run 100% locally.
